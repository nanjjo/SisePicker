# SisePicker v1.0

네이버 부동산·시세통의 단지별 매매/전세를 가져와 검수하고 생활권 PPT에 추가하는 Windows 앱입니다.

## 실행
`dist/SisePicker.exe`를 실행합니다. Python/Node 설치는 필요 없습니다. 네이버 부동산이 기본 탭이며 뒤에 시세통, 이미지 OCR이 있습니다.

## 네이버 부동산
1. 연두색 **처음 사용 · 즐겨찾기 등록 방법 안내**를 열고 안내 링크를 Chrome/Edge 즐겨찾기에 등록합니다.
2. 네이버에서 단지를 선택하고 단지정보를 연 뒤 즐겨찾기를 실행합니다.
3. **매매·전세 수집 시작**을 누릅니다. 단지명·진행 단계·읽은 수가 표시됩니다. 수집 중 단지/필터를 변경하지 마세요.
4. 완료 또는 부분 수집 결과를 확인하고 복사한 뒤 앱의 주황색 붙여넣기를 누릅니다.
5. 표, 세대수, 승인일을 검수하고 **PPT에 추가**합니다. 부분 수집은 원본 확인 체크가 필요합니다.

전용면적이 기본이며 공급평수를 선택할 수 있습니다. 40평 미만 필터는 공급평수 기준이 기본입니다. 76D1/83A-2의 뒤 타입은 평형 숫자에 포함되지 않습니다. 예를 들어 116A/84㎡에서 전용은84입니다. 결과 헤더는 `단지명 24' 780^`입니다. 매매/전세는 각각 최저 호가이며 실제 거래가격이 아닙니다. 상단 가격·층 등 추가 검색조건은 수집 전에 직접 해제하세요.

**2026-10-11 면적 형식 수정 적용:** 기존 네이버 즐겨찾기를 새 안내 페이지 링크로 교체하고, 기존 웹 패널을 닫은 뒤 실행하세요. 실행 파일 교체만으로 브라우저 즐겨찾기는 갱신되지 않습니다.

## 시세통·이미지 OCR
시세통 탭의 안내로 별도 즐겨찾기를 등록하고 화면의 단지를 골라 복사·붙여넣습니다. 웹 입력은 자동 저장하지 않습니다.
이미지 OCR 탭은 캡처 붙여넣기/파일 열기, 원본 자동 확대와 편집 표를 제공합니다. 노란 칸은 확인 필요, 수정된 정상 형식은 초록입니다. `?`는 미확인, `-`는 값 없음입니다. 불확실한 소수점을 추측하지 않으며 노란 칸이 남으면 출력이 보류됩니다. OCR 자동 복사/PPT 옵션은 이 탭에서 사용합니다.

## PPT·생활권·기록
생활권 관리에서 PPT의 생활권 제목을 가져오고 표에서 추가·수정·삭제합니다. 앱 목록 변경으로 원본 PPT 제목을 바꾸지 않습니다. 새 결과는 선택 페이지의 가운데 같은 위치에 추가되므로 겹친 상자는 직접 이동하세요.
기록은 PPT 폴더의 records에 매매값만 저장합니다. 전용55~65㎡는24평,80~90㎡는34평으로 분류하고 나머지는 제외합니다. 탭들은 편집 결과 하나를 공유합니다.

## 개발과 검증
빌드 PC: Python3.12 x64와 Node.js. `build.bat`가 로컬 가상환경·고정 의존성·테스트·단일 exe·자체검사를 처리합니다.
```bat
build.bat
.venv\Scripts\python.exe main.py
```
최종 코드에서 Python92개와 JavaScript 검사, 패키지 자체검사 통과. 실제 Python 미설치 별도 PC 검증은 하지 않았습니다. 작은 이미지 OCR과 외부 사이트 구조 변경에는 한계가 있습니다. 최근 면적 수정 후 실제 브라우저 전체 수집 흐름은 추가 현장 확인 대상입니다.
